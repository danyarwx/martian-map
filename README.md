# Martian Map

NASA Space Apps 2026: Interplanetary Survival Guide: Martian Map.
A layered local map for planning and carrying out a Marswalk.

## Run

```bash
npm install
npm run fetch-data   # downloads rover route data into public/data
npm run dev
```

Project context for Claude Code is in `CLAUDE.md`. Team setup is in `SETUP.md`.
